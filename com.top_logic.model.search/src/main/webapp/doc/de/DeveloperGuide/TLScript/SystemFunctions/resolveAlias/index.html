Syntax

	resolveAlias($text)

Beschreibung

Ersetzt alle Konfigurationsvariablen (Aliase), die in einem Text vorkommen, durch ihre Werte. Eine Konfigurationsvariable (Alias) wird als ihr Name in Prozentzeichen geschrieben, z. B. %HOST%. Ihr Wert wird in der Anwendungskonfiguration definiert und kann durch eine Umgebungsvariable oder einen in der Anwendung gespeicherten Wert überschrieben werden.

Um den Wert einer einzelnen Konfigurationsvariablen (Alias) über ihren Namen zu lesen, verwenden Sie stattdessen configVariable(name), z. B. configVariable('EHOME_DISCOVERY').

Parameter

Name Typ Beschreibung Pflicht Default
text Zeichenkette Der Text mit den Konfigurationsvariablen (Aliasen), die ersetzt werden sollen. ja

Rückgabewert

Typ: Zeichenkette

Der gegebene Text, in dem jede Konfigurationsvariable (Alias) durch ihren Wert ersetzt ist.

Beispiele

	 resolveAlias('%HOST%:%PORT%')

Ausgabe: localhost:8090

Unter der Voraussetzung, dass für die Konfigurationsvariable (Alias) %HOST% in der Konfiguration localhost und für %PORT% 8090 angegeben wurde.
