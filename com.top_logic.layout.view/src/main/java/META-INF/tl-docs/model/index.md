# Model types in applications

An application describes its data in `*.model.xml`: classes, enumerations and datatypes. The built-in datatypes of `tl.core` (strings, numbers, dates, …) cover most attributes. The articles of this chapter describe what an application does when a value needs a type of its own - how the value is stored, read, displayed and entered, and which engine extension points take part in that.
