TopLogic bietet eine Historie der Fachobjekte an. Mit diesen Funktionen können Fachobjekte in verschiedenen Versionen ermittelt werden, bzw. die Revision eines historischen Objektes ermittelt werden.

Eine Revision ist ein Fachobjekt vom Typ tl.core:Revision.

Jeder Nutzer darf eine Revision mit Nummer, Zeitpunkt und Commit-Nachricht lesen. Den Autor einer Revision erhalten nur Administratoren und der Autor selbst; für alle anderen Nutzer ist author leer.
