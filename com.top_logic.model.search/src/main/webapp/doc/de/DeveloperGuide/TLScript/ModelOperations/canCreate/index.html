Syntax

$parent.canCreate($reference)

canCreate($parent, $reference)

canCreate($parent, $reference, $type)

Beschreibung

Prüft, ob der aktuell angemeldete Nutzer ein neues Element in der angegebenen Kompositionsreferenz des angegebenen übergeordneten Objekts anlegen darf, und liefert einen Wahrheitswert.

Der Nutzer benötigt das Anlegerecht für den Typ des neuen Elements im Kontext des übergeordneten Objekts sowie den Schreibzugriff auf die Kompositionsreferenz (dieselbe Prüfung, die das Hinzufügen eines Elements zur Referenz absichert). Standardmäßig ist der Typ des neuen Elements der Zieltyp der Referenz. Soll ein Element einer Spezialisierung angelegt werden, wird dessen Typ als drittes Argument angegeben; geprüft wird dann das Anlegerecht für diese Spezialisierung. Die Funktion filtert nicht und schlägt nur fehl, wenn der angegebene Typ nicht zum Zieltyp der Referenz passt.

Die Prüfung erfolgt für den aktuell angemeldeten Nutzer und folgt denselben Regeln wie die implizite Berechtigungsprüfung: standardmäßige Verweigerung, Rollenvererbung entlang der Sicherheitshierarchie sowie Vollzugriff für Administratoren oder Ausführungen im Systemkontext.

Parameter

NameTypTypbeschreibungPflichtStandardwert
parentFachobjektDas übergeordnete Objekt, das das neue Element aufnimmt.ja
referenceAttributDie Kompositionsreferenz (TLStructuredTypePart), in die das Element angelegt wird.ja
typeTypDer Typ des anzulegenden Elements. Muss der Zieltyp der Referenz oder eine Spezialisierung davon sein.neinDer Zieltyp der Referenz.

Rückgabewert

Typ: Wahrheitswert

true, wenn der aktuelle Nutzer ein Element in der angegebenen Referenz des übergeordneten Objekts anlegen darf, sonst false.

Beispiele

Beispiel 1

$project.canCreate(`my.module:Project#milestones`)

Ausgabe: Ob der angemeldete Nutzer dem Projekt einen Meilenstein hinzufügen darf.

Beispiel 2

$project.canCreate(`my.module:Project#milestones`, `my.module:FinalMilestone`)

Ausgabe: Ob der angemeldete Nutzer dem Projekt einen Abschlussmeilenstein (eine Spezialisierung des Meilensteintyps) hinzufügen darf.
