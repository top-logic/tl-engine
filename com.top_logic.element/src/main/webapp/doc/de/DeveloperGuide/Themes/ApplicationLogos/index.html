Eine Applikation zeigt an mehreren Stellen ein Logo an. Alle diese Logos werden über Ressourcen mit festen Namen ausgeliefert und können von der Applikation ersetzt werden, ohne dass Konfiguration angepasst werden muss.

Die Logo-Ressourcen

Ressource Anzeigeort Theme-Variable
/images/appLogo.svg Kopfbereich der ausgeklappten Sidebar sowie Login- und Logout-Seite IMAGES_APP_LOGO, com.top_logic.layout.Icons.APP_LOGO
/images/appLogoMinimized.svg Kopfbereich der eingeklappten (minimierten) Sidebar IMAGES_APP_LOGO_MINIMIZED
/images/favicon.png Browser-Tab neben dem Namen der Anwendung DEFAULT_ICON

Die beiden Sidebar-Logos werden in sehr unterschiedlichen Größen dargestellt. Orientieren Sie sich an den mitgelieferten Vorlagen: appLogo.svg ist ein liegendes Logo mit Schriftzug (Standard-Vorlage 220 × 50), appLogoMinimized.svg eine quadratische Bildmarke ohne Schriftzug (Standard-Vorlage 64 × 64).

Eigene Logos hinterlegen

Legen Sie in Ihrer Applikation eine Datei mit demselben Namen an derselben Stelle ab:

src/main/webapp/images/appLogo.svg
src/main/webapp/images/appLogoMinimized.svg
src/main/webapp/images/favicon.png

Die Ressourcen der Applikation haben Vorrang vor den gleichnamigen Ressourcen der Engine-Module. Es ist keine weitere Konfiguration nötig, insbesondere müssen die Theme-Variablen nicht angepasst werden.

Logos pro Theme austauschen

Soll ein Logo nur in einem bestimmten Theme anders aussehen (z.B. eine helle Variante für ein dunkles Theme), legen Sie die Datei zusätzlich unterhalb des Theme-Verzeichnisses ab:

src/main/webapp/themes/<theme-id>/images/appLogo.svg

Bilder werden immer zuerst im aktiven Theme gesucht, danach in dessen Eltern-Themes und erst zuletzt unter dem angegebenen Pfad im Wurzelverzeichnis der Web-Applikation. Ein Theme, das keine eigene Variante mitbringt, verwendet also automatisch die Datei aus /images/.

Andere Dateinamen verwenden

Wenn Sie die Namenskonvention nicht übernehmen wollen, biegen Sie stattdessen die Theme-Variable um – entweder im Theme-Editor oder direkt in der Datei src/main/webapp/WEB-INF/themes/<theme-id>/theme-settings.xml:

<settings>
    <icon name="IMAGES_APP_LOGO"
        value="/images/mein-logo.svg"
    />
    <icon name="IMAGES_APP_LOGO_MINIMIZED"
        value="/images/mein-logo-klein.svg"
    />
</settings>

Die Theme-Variablen liefern lediglich die Vorbelegung der Sidebar-Ansicht (LogoViewConfiguration). In einem Layout kann das Logo für eine einzelne Sidebar auch direkt angegeben werden:

<view class="com.top_logic.layout.structure.LogoViewConfiguration"
    logo="/images/mein-logo.svg"
    logoMinimized="/images/mein-logo-klein.svg"
/>

Favicon

Das Favicon wird dem Browser über die Theme-Variable DEFAULT_ICON bekannt gemacht, die standardmäßig auf /images/favicon.png zeigt.

Um das Favicon auszutauschen, legen Sie wie bei den Logos eine eigene Datei unter diesem Pfad in Ihrer Applikation ab. Auch die Theme-spezifische Ablage unter src/main/webapp/themes/<theme-id>/images/favicon.png funktioniert wie bei den Logos. Anders als bei den SVG-Logos wird hier ein Rasterbild erwartet.
