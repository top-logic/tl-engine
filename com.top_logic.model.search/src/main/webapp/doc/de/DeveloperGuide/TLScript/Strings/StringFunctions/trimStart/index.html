Syntax

	$string.trimStart()

trimStart($string)

Beschreibung

Entfernt allen Leerraum (Leerzeichen, Tabulatoren, Zeilenumbrüche und andere Unicode-Leerraumzeichen) am Anfang der Zeichenkette string. Leerraum innerhalb der Zeichenkette bleibt erhalten.

Ist string null, so ist das Ergebnis null. Andere Werte werden zunächst in eine Zeichenkette umgewandelt.

Parameter

Name Typ Beschreibung Pflicht Default
string Zeichenkette Zeichenkette, aus der der Leerraum entfernt werden soll. ja

Rückgabewert

Typ: Zeichenkette

string ohne führenden Leerraum, bzw. null, wenn string null ist.

Beispiele

	trimStart("  Hello  world!  ")

Ausgabe: "Hello world! "
