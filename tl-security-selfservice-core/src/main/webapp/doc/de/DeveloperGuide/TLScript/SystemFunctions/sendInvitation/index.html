Syntax

sendInvitation($invitation)

Beschreibung

Versendet eine Einladungs-E-Mail an den im invitation-Objekt hinterlegten Empfänger. Die E-Mail enthält einen Registrierungslink, über den der Eingeladene sein Konto anlegen kann. Die E-Mail wird durch den im InvitationModule konfigurierten Ausdruck invitation-mail versendet, mit Betreff und Inhalt aus dessen Option invitation-text, in der Sprache der Einladung.

Der Registrierungslink wird aus der öffentlichen Adresse der Applikation (Variable tl_host, Alias %HOST%) und der in der Option invitation-link des InvitationModule konfigurierten Seite gebildet. Ohne konfigurierte öffentliche Adresse werden Schema, Host und Port aus der aktuellen Anfrage übernommen; die Funktion kann dann nur während der Bearbeitung einer Anfrage verwendet werden, z. B. in einem Kommando der klassischen oder der React-Oberfläche, nicht aber in einem zeitgesteuerten Skript.

Nur eine offene Einladung kann versendet werden. Eine abgelaufene Einladung muss zuerst erneuert werden, wodurch sie einen neuen Link und eine neue Gültigkeit erhält.

Damit diese Funktion genutzt werden kann, muss das Modul tl-security-selfservice-core in der Applikation eingebunden und der E-Mail-Versand konfiguriert sein.

Parameter

Name Typ Beschreibung Pflicht Default
invitation Fachobjekt (tl.security.selfservice:Invitation) Die offene Einladung, deren Empfänger die Einladungs-E-Mail erhalten soll. Die Einladung muss eine gültige E-Mail-Adresse im Attribut email hinterlegt haben. ja

Rückgabewert

Typ: Wahrheitswert

Ob der Versand der Einladungs-E-Mail erfolgreich war.

Beispiele

Einladung versenden

sendInvitation($invitation)

Ausgabe: true

Versendet die Einladungs-E-Mail an die im Attribut email von $invitation hinterlegte Adresse.

Einladung erstellen und versenden

{
  invitation = new(`tl.security.selfservice:Invitation`);
  set($invitation, `tl.security.selfservice:Invitation#email`, "new.user@example.com");
  sendInvitation($invitation);
}

Ausgabe: true

Erstellt eine neue Einladung für die angegebene E-Mail-Adresse und versendet die Einladungs-E-Mail direkt im Anschluss.
