Syntax

	$object.modifiedRevision()

Description

Determines the revision in which a business object was last modified.

A modification is a change of any stored attribute value of the object. This includes values that are not stored in the object's own table row, such as references stored in link tables and translations of internationalized attributes.

Compositions are handled depending on how their parts are stored:

  • Parts stored in a link table (the default): Adding a part to or removing a part from the composition counts as a modification of the container, a change within a part does not.
  • Parts that store their container in their own table row: Every change of such a part also counts as a modification of the container.

To find the changes of a whole composition subtree, use the function changeLog, e.g. $object.changeLog(1, true).

For each table in which the attributes of the object's type store values, the function executes an indexed database query. It can be used in table columns, but it is not free: Prefer it over loading the full change history, but avoid evaluating it needlessly for large numbers of objects.

Notes for Java developers

The Java entry point for this computation is com.top_logic.element.changelog.LastChangeRevision#of(TLObject). In contrast, TLObject#tLastModificationDate(), TLObject#tLastModificationTime(), TLObject#tLastModifier() and the life-cycle attribute modified only reflect changes of the object's own table row.

Parameters

Name Type Description Mandatory Default
object Business object The realm object for which the change revision is to be determined. yes

Return value

Type: Revision

The revision in which the object was changed the last time.
