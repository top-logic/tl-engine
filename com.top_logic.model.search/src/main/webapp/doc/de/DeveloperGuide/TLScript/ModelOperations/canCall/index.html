Syntax

canCall($call)

Beschreibung

Prüft, ob der aktuell angemeldete Nutzer den angegebenen Aufruf einer konfigurierten TL-Script-Funktion ausführen darf, ohne ihn auszuführen. Ausgewertet werden nur die Argumente des Aufrufs.

Bei einem privilegierten Skript wird das Sicherheitsobjekt berechnet und die Kommandogruppe darauf geprüft; bei einer Sammlung von Sicherheitsobjekten auf jedem Element. null und eine leere Sammlung verbieten den Aufruf. Eine einfache konfigurierte Funktion darf immer aufgerufen werden. Typische Verwendung: die Ausführbarkeit eines Kommandos, das eine privilegierte Funktion aufruft.

Parameter

NameTypTypbeschreibungPflichtStandardwert
callFunktionsaufrufEin Aufruf einer konfigurierten TL-Script-Funktion. Alles andere ist ein Compilerfehler.ja

Rückgabewert

Typ: Wahrheitswert

true, wenn der aktuelle Nutzer den Aufruf ausführen darf, sonst false.

Beispiele

Beispiel 1

canCall(approveMilestone($milestone))

Ausgabe: Ob der angemeldete Nutzer die Funktion approveMilestone mit dem angegebenen Meilenstein aufrufen darf.
