Syntax

sendInvitation($invitation)

Description

Sends an invitation e-mail to the recipient specified in the invitation object. The e-mail contains a registration link that the invitee can use to create their account. The e-mail is sent by the invitation-mail expression configured in the InvitationModule, with the subject and content of its option invitation-text, in the language of the invitation.

The registration link is built from the public address of the application (variable tl_host, alias %HOST%) and the page configured in the option invitation-link of the InvitationModule. Without a configured public address, scheme, host and port are taken from the current request; the function then only works while a request is processed, e.g. in a command of the classic or the React user interface, but not in a scheduled script.

Only an open invitation can be sent. An expired invitation must be renewed first, which gives it a new link and a new validity.

To use this function, the tl-security-selfservice-core module must be included in the application and e-mail dispatch must be configured.

Parameters

Name Type Description Mandatory Default
invitation Business object (tl.security.selfservice:Invitation) The open invitation whose recipient should receive the invitation e-mail. The invitation must have a valid e-mail address set in its email attribute. yes

Return value

Type: Truth value

Whether the invitation e-mail was sent successfully.

Examples

Send an invitation

sendInvitation($invitation)

Output: true

Sends the invitation e-mail to the address stored in the email attribute of $invitation.

Create and send an invitation

{
  invitation = new(`tl.security.selfservice:Invitation`);
  set($invitation, `tl.security.selfservice:Invitation#email`, "new.user@example.com");
  sendInvitation($invitation);
}

Output: true

Creates a new invitation for the given e-mail address and immediately sends the invitation e-mail.
