Scenario A: User Sends Chat Message (pre + post turn agents)

Chat Flow with Background Agents
User: "Show me all customer records" │ ▼ ChatProcessor.executeOrchestrator() │ │ ── PRE-TURN PHASE ────────────────────────── │ ▼ for (agent : registry.getBackgroundAgents(PRE_TURN, CHAT)) { │ │ e.g. SecurityGate (authoritative) │ ▼ BackgroundAgentExecutor.executeSync(agent, chatContext) │ ├─ InputAdapter: ChatContextAdapter (full-chat) │ → ConversationSerializer.serializeFullChat() │ ├─ Agent invoked: "Check if this request is allowed..." │ → Agent reasons about business rules │ → Returns "PASS" or "BLOCK: contains PII request" │ ├─ OutputHandlers: AuditLogHandler logs the decision │ └─ Result: PASS ✓ (or BLOCK → return block-message to user, stop) │ │ ── MAIN AGENT PHASE ───────────────────────── │ ▼ response = orchestrator.invoke(message) → "Here are the customer records: ..." │ │ ── POST-TURN PHASE ────────────────────────── │ ▼ for (agent : registry.getBackgroundAgents(POST_TURN, CHAT)) { │ │ e.g. ReviewAgent (advisory, async) │ ▼ BackgroundAgentExecutor.executeAsync(agent, chatContext) │ (fire-and-forget in background thread) │ ├─ InputAdapter: ChatContextAdapter (last-turn) │ → ConversationSerializer.serializeLastTurn() │ ├─ Agent invoked: "Review this conversation turn..." │ → Finds issue: "Agent exposed raw PII without masking" │ → Calls gitea.create_gitea_issue tool │ → Returns issue summary │ ├─ OutputHandlers: NotificationHandler │ → Pushes ReviewNotification to SSE stream │ → User sees warning badge in chat UI │ └─ Result: ISSUE_FOUND (advisory — does not block) │ ▼ Response delivered to user

Scenario B: Scheduled Agent Runs at 2 AM

Scheduled Compliance Check
02:00 — Scheduler polling loop fires │ ▼ BackgroundAgentTask.runHook() (extends StateHandlingTask) │ ▼ BackgroundAgentExecutor.execute("ComplianceChecker", appContext) │ ├─ InputAdapter: AutonomousInputAdapter │ → Returns: "Run your daily compliance check." │ ├─ Agent invoked with trigger message │ → Agent uses tools autonomously: │ tl.listInstances("myApp", "SensitiveRecord") │ tl.executeTLScript("filter expired records...") │ gitea.create_gitea_issue("3 records violate retention") │ → Returns summary: "Found 3 violations, filed issue #42" │ ├─ OutputHandlers: │ → AuditLogHandler: logs to system audit │ → NotificationHandler: pushes admin notification │ → SchedulerLogHandler: writes to TaskLog (admin UI) │ └─ Result: ISSUE_FOUND │ ▼ Scheduler records: TaskLog.taskEnded(WARNING, "3 violations found") → Visible in admin UI under Scheduler tasks

Scenario C: Admin Triggers On-Demand Check

Manual REST Trigger
Admin clicks "Run Model Quality Check" button │ ▼ POST /chat/background/ModelQualityChecker │ ▼ ChatServlet.handleBackgroundTrigger() │ ├─ Auth: TLContext.currentUser() → admin ✓ ├─ Role: allowed-roles=["admin"] → hasRole() ✓ │ ▼ BackgroundAgentExecutor.executeAsync("ModelQualityChecker", appContext) │ ├─ InputAdapter: ScriptInputAdapter │ → Evaluates TLScript: │ all(`myModule:MyType`).filter(t -> t.get(`description`) == null) │ → Returns: "Widget: null\nGadget: null\n..." │ ├─ Agent invoked: "Review these model elements..." │ → Returns: "2 types missing descriptions: Widget, Gadget" │ ├─ OutputHandlers: │ → NotificationHandler: pushes info notification │ └─ Result: ISSUE_FOUND │ ▼ HTTP 202 Accepted (async — result arrives via SSE notification)

Summary

Trigger Scope Execution Can Block?
Post-turn Chat Async (background thread) No (always advisory)
Pre-turn Chat Sync (before Orchestrator) Yes (if authoritative)
Scheduled Application Scheduler thread pool No (no chat to block)
On-demand Either Async (background thread) No (fire-and-forget)
