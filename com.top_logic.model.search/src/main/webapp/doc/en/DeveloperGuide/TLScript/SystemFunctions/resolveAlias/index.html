Syntax

	resolveAlias($text)

Description

Replaces all configuration variables (aliases) occurring in a text with their values. A configuration variable (alias) is written as its name enclosed in percent signs, e.g. %HOST%. Its value is defined in the application configuration and can be overridden by an environment variable or a value stored in the application.

To read the value of a single configuration variable (alias) by its name, use configVariable(name) instead, e.g. configVariable('TRANSLATION_ENABLED').

Parameters

Name Type Description Mandatory Default
text String The text containing the configuration variables (aliases) to replace. yes

Return value

Type: String

The given text in which each configuration variable (alias) is replaced by its value.

Examples

	 resolveAlias('%HOST%:%PORT%')

Output: localhost:8090

Provided that localhost was specified for the configuration variable (alias) %HOST% in the configuration, and 8090 was specified for %PORT%.
