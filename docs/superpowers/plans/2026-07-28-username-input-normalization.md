# Account name input normalization & self-provisioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trim account-name input at the two chokepoints (`Person.create` / `Person.byName`), validate the name (characters + length) only on create, make the default name pattern e-mail-friendly, and let self-provisioning from an e-mail rely on the existing case-insensitive handling — completing Ticket #29423 part 2.

**Architecture:** All behavior is added at the two existing chokepoints in `com.top_logic.knowledge.wrap.person.Person`. A new pure helper `Person.normalizeName(String)` trims (case-preserving). `Person.create` trims, then validates via the already-existing (but so-far-uncalled) `PersonManager.validatePersonName(String)`, then runs the existing case-insensitive duplicate check. `Person.byName` trims before the (already case-insensitive) lookup, which transparently covers login, both password-reset dialogs and external auth. No new derivation code for self-provisioning.

**Tech Stack:** Java (TopLogic engine, module `com.top_logic`), JUnit 4 KB tests (`AbstractDBKnowledgeBaseTest` / `TestPerson`), TypedConfiguration, `ResKey`/`I18NConstants`.

/**
 * Normalizes an account (login) name for storage and lookup: strips leading and trailing
 * whitespace while preserving the case. {@code null} is passed through.
 *
 * @param name
 *        The raw name, may be {@code null}.
 * @return The trimmed name, or {@code null} if the argument was {@code null}.

public static String normalizeName(String name) {
	return name == null ? null : name.strip();

```java
public static Person byName(KnowledgeBase kb, String name) {
	String normalized = normalizeName(name);
	if (kb == getDefaultKnowledgeBase()) {
		return fromCache(kb, normalized);
	}
	if (StringServices.isEmpty(normalized)) {
		return null;
	}
	KnowledgeObject result =
		(KnowledgeObject) kb.getObjectByAttribute(OBJECT_NAME, AbstractWrapper.NAME_ATTRIBUTE, normalized);
	return result == null ? null : result.getWrapper();
}
```

`fromCache` already lower-cases via the cache key mapper; only add the trim: `String normalized = normalizeName(name);` then use `normalized` in the `isEmpty` check and `lookup`.
